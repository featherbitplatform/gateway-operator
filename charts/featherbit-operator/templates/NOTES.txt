featherbit-operator {{ .Chart.AppVersion }} installed in namespace {{ .Release.Namespace }}.

Create a first gateway:

  kubectl apply -f - <<YAML
  apiVersion: featherbit.io/v1alpha1
  kind: FeatherbitGateway
  metadata:
    name: demo
  spec: {}
  YAML

  kubectl get featherbitgateways
  kubectl get routes,policies,supernodes,pluginconfigs,stores,consumers

Order: the operator can be installed before or after the gateway. Resources
created while it is absent are reconciled once it starts; with
webhook.failurePolicy=Fail, creating featherbit.io resources is rejected while
the operator is down.
